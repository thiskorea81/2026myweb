# 👨‍🏫 스마트 학급 & 동아리 관리 다이어리 (with AI)

교사의 반복적이고 소모적인 행정 업무를 획기적으로 줄이고, 학생 관리에 더욱 집중할 수 있도록 돕기 위해 제작된 **AI 기반 학급/동아리 관리 웹 애플리케이션**입니다. Google Gemini AI와 Firebase를 연동하여 학생 데이터 관리, 상담 기록, 그리고 **생활기록부 초안 자동 생성**까지 완벽하게 지원합니다.

---

## 🌟 주요 기능

### 1. 👥 학생 통합 관리 (학급 & 동아리)
* **엑셀/CSV 일괄 등록:** 학생 명단, 성적, 동아리 활동 내역을 엑셀에서 복사해 한 번에 등록.
* **사진 일괄 등록:** `학번.jpg` (예: 10501.jpg) 파일들을 드래그 앤 드롭하면 자동으로 학생 프로필에 압축 연동.
* **학생 종합 기록부:** 기본 정보, 상담, 출결, 성적을 한눈에 확인하고 PDF/A4 양식으로 개별 및 일괄 인쇄.

### 2. ✨ AI 생활기록부 자동 완성 (NEIS 최적화)
* **학급 생기부:** 교사의 평소 관찰 메모와 상담/출결 기록을 종합하여 `자율활동(1500 byte)`, `진로활동(2100 byte)`, `행동특성 및 종합의견(1500 byte)` 초안을 AI가 자동 작성.
* **동아리 특기사항:** 학생들이 제출한 활동 소감(설문지)을 바탕으로 `동아리 특기사항(1500 byte)` 자동 완성.
* **버전 관리 및 맞춤 수정:** "리더십을 더 강조해 줘" 등의 추가 지시를 통해 초안을 무한 수정 및 버전별 비교 가능.
* **데이터 내보내기:** 완성된 최종 생기부 기록을 전체 학생 CSV 파일로 한 번에 다운로드하여 나이스(NEIS) 입력 효율 극대화.

### 3. 🤖 AI 업무 비서 채팅
* 학생 이름을 언급하면 해당 학생의 성적, 상담, 출결 데이터를 분석하여 맞춤형 지도 방안 제공.
* `#업무` 태그를 사용하여 교사의 업무 일지 내용을 검색 및 요약.
* AI와 나눈 유용한 대화는 즉시 해당 학생의 **[🤖 AI 노트]** 탭으로 영구 보존 가능.

## 🛠 사용 기술 (Tech Stack)
* **Frontend:** Vue 3 (Composition API), Tailwind CSS
* **State Management:** Pinia
* **Backend / DB:** Firebase (Firestore)
* **AI Integration:** Google Gemini API (`@google/genai`)

## 📖 핵심 사용 설명서 (User Guide)

### 📊 데이터 일괄 등록 방법 (엑셀 활용)
* **학생 명단:** 엑셀 첫 줄에 `학번, 이름`을 포함하여 복사 후 **[학생 일괄 등록]** 창에 붙여넣기.
* **성적 등록:** 첫 줄에 `학번, 시험명`을 반드시 포함하고, 나머지 열은 과목명(국어, 수학 등)이나 석차로 자유롭게 기입.
* **사진 등록:** 사진 파일 이름을 `10501.jpg`처럼 학번으로 변경한 뒤 **[📸 사진 일괄 등록]**을 눌러 파일들을 한 번에 선택.
* **동아리 활동:** 설문지(구글 폼) 결과를 엑셀로 열어 `학번, 활동명, 내용` 열을 포함하여 복사 후 **[동아리 활동 일괄 등록]** 창에 붙여넣기.

### 📝 생기부 AI 작성 흐름 (Workflow)
1. **학기 중:** 학생 상세 창의 **[📝 생기부]** 탭에서 `📌 평소 관찰 메모 (수시 기록용)` 란에 학생의 특징을 단어로 짧게 메모해 둡니다.
2. **학기 말:** **[✨ 새 초안 자동 생성]** 버튼을 누릅니다.
3. AI가 상담 기록과 관찰 메모를 엮어 글자 수(1500/2100 바이트)에 맞춘 완벽한 초안을 제시합니다.
4. 수정이 필요하면 하단 채팅창에 "진로활동에 ~내용을 추가해 줘"라고 입력하여 수정안을 받습니다.
5. 마음에 드는 버전을 찾았다면 **[⬆️ 최종 기록으로 가져오기]** 버튼을 눌러 NEIS 입력용 창으로 확정 짓습니다.
6. 학급 관리 메인 화면에서 **[⬇️ 전체 생기부 CSV 다운로드]**를 눌러 나이스에 복사해 넣습니다.

### 🖨️ 학생 종합 기록부 인쇄
* **단일 인쇄:** 학생 상세 창 우측 상단의 **[🖨️ 학생 기록부 인쇄]** 버튼 클릭.
* **일괄 인쇄:** 명렬표에서 원하는 학생들의 체크박스를 선택한 후 우측 상단의 **[🖨️ 일괄 인쇄]** 버튼 클릭. (한 명당 A4 1장씩 자동으로 나뉘어 인쇄됩니다.)
